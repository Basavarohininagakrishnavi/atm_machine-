# atm_machine-
Verilog HDL based ATM controller project implementing card authentication, PIN verification, balance enquiry, withdrawal, deposit, PIN change, security features, and FSM-based transaction control.
ATM Controller Using Verilog HDL


📌 Project Description

This project presents a digital Automated Teller Machine (ATM) controller developed using Verilog HDL. The system models essential ATM operations such as card identification, PIN authentication, balance enquiry, cash withdrawal, deposit, PIN change, and card ejection.

The project focuses on applying digital design concepts, Finite State Machine (FSM) based control, RTL design, and simulation to a practical banking application.

---

🎯 Why We Developed This Project

The main purpose of this project is to understand how a real-world system can be represented and controlled using digital logic.

Through this project, we learned and applied:

- Verilog HDL
- Finite State Machine (FSM) design
- Digital system control
- Registers and counters
- Authentication and security concepts
- RTL design
- Functional verification using simulation
- Testbench-based verification

The project also helped us understand how different operations can be organized into a systematic sequence using state-based control.

---

✨ Features

The ATM controller provides the following features:

- 💳 Card identification
- 🔐 PIN authentication
- 🔢 Limited PIN attempts
- 🚫 Temporary card blocking after incorrect attempts
- 💰 Balance enquiry
- 💵 Cash withdrawal
- ➕ Deposit operation
- 🔑 PIN change
- 💸 Cash output indication
- 📤 Card ejection
- 👥 Support for multiple registered accounts
- ⏱️ Timer-based security control
- 🔄 FSM-based transaction control
- 📊 RTL design visualization
- 🧪 Testbench-based simulation and verification
