# ATM Controller Using Verilog HDL
Verilog HDL based ATM controller project implementing card authentication, PIN verification, balance enquiry, withdrawal, deposit, PIN change, security features, and FSM-based transaction control.
ATM Controller Using Verilog HDL




💡 From Need to Idea to Project

Every functionality begins with a need, and every project begins with an idea.

An ATM is a simple real-world example where different users perform different operations through a single system. This inspired us to represent the basic functionality of an ATM as a digital system using Verilog HDL.

Our project implements an ATM Controller that models essential banking operations and controls them using a Finite State Machine (FSM) based digital design approach.

🚀 Project Overview

The ATM controller supports multiple operations, including:

- 💳 Card Identification
- 🔐 PIN Verification
- 💰 Balance Enquiry
- 💵 Cash Withdrawal
- ➕ Deposit
- 🔑 PIN Change
- 🚫 Incorrect PIN Attempt Handling
- ⏱️ Temporary Card Blocking
- 📤 Card Ejection
- 🔄 FSM-Based Control

The design was developed, simulated, and verified using a Verilog testbench. RTL representation and simulation waveforms were also analyzed as part of the project.

🎯 Why This Project?

The purpose of this project was not only to create an ATM model, but also to understand how a real-world requirement can be converted into a digital hardware design.

Through this project, we gained practical exposure to:

- Verilog HDL
- FSM-based digital design
- RTL design
- Registers and counters
- Digital authentication concepts
- Testbench development
- Simulation and verification
- Team-based project development

🧪 Verification

The design was tested through simulation for different ATM operations and security conditions.

The testbench was used to verify:

- Card identification
- Correct and incorrect PIN handling
- Temporary card blocking
- Balance enquiry
- Withdrawal
- Deposit
- PIN change
- Cash output
- Card ejection
